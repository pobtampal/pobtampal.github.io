01. About Me

I'm a security engineer focused on building AI-assisted defenses. Attackers now use AI too, so defenders need tools that move just as fast.

At WanAware, I built two vulnerability scanners from the ground up: one for live web applications and one for source code repositories. Both detect and prioritize every finding, then explain how to fix it, so developers can act quickly without needing to be security experts. I also ran a SIEM proof-of-concept with Wazuh to assess how well we could monitor customer telemetry.

I'm currently working toward CompTIA Security+ and looking to bring a builder's mindset to a full-time security team.

GCP-Sec: Cloud Findings Analyzer

A Go CLI that turns GCP Security Command Center exports into prioritized, actionable reports. It scores each finding from 0 to 100 using multiple risk factors, maps compliance violations (CIS, PCI-DSS, HIPAA, SOC 2, NIST, and more), and generates remediation guidance as Markdown, JSON, HTML, or CSV. The repo itself is protected by a SAST pipeline in GitHub Actions.
